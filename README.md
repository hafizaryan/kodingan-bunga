# Kodingan Bunga (Kado)

Halaman web statis berisi ucapan dan animasi bunga yang mekar, dibuat sebagai hadiah digital mengikuti tren video bunga di TikTok. Halaman pembuka menampilkan ucapan per huruf dan sebuah tombol yang mengarah ke halaman animasi bunga.

Kode animasi bunga diadaptasi dari CodePen milik Md Usman Ansari (https://codepen.io/mdusmanansari/pen/BamepLe), dengan halaman indeks yang disusun oleh Septian Dwi Cahyo.

## Isi Halaman

- `index.html` - halaman pembuka berisi ucapan "HAI RAHMA <3", teks hadiah, dan tombol menuju halaman bunga. Teks ucapan dapat diubah dengan mengganti isi elemen `<span>` pada berkas ini.
- `flower.html` - halaman animasi bunga mekar yang digambar murni dengan HTML dan CSS.
- `main.js` - JavaScript kecil untuk halaman bunga.
- `css/` dan `scss/` - stylesheet hasil kompilasi dan sumber SCSS animasi.
- `img/` - berkas gambar pendukung, termasuk ikon bunga.

## Teknologi

- HTML5
- CSS3 dan SCSS untuk animasi bunga
- JavaScript murni

## Cara Menjalankan

Tidak ada proses build. Buka berkas `index.html` langsung di browser, atau jalankan server statis seperti `npx serve .` lalu akses alamat yang ditampilkan.
